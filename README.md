## Built With

### Web Site

- HTML5
- CSS3
- Google Fonts
  - Young Serif
  - Outfit

### Recipe Page Generation

- Python
- Markdown
- Jinja
- BeautifulSoup

The recipe data is written in Markdown and can be converted into the corresponding HTML recipe pages using the generation script.
